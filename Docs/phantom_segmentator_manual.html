Section 1

Overview

Phantom Segmentator automates the placement of rod-shaped segment masks onto CT calibration phantoms. For each phantom type the module determines the rigid-body transformation from phantom coordinates to CT (RAS) space, then rasterizes analytically defined cylinders — avoiding the manual contouring that seed-based or threshold-based tools require.

Each phantom type uses a dedicated registration strategy:

  • QMC-Phantom and 3Dprinted-QMC use seed-based region-growing followed by PCA axis determination and a 3-point landmark transform.
  • MicroCT-Phantom uses a geometry-only markup-line approach — two user-placed lines define the phantom pose without any region-growing.

Segment names are globally unique across phantom types (Ref_800, P_800, Z_800), so all three phantoms can be evaluated in the same Slicer scene without segment conflicts.

Section 2

Setup

No separate installation step is required beyond adding the extension to your Slicer extensions path.

  1. Open 3D Slicer and load the CT volume of the phantom scan.
  2. Navigate to Modules → Zesbo → Phantom Segmentator.
  3. In the Phantom-Setup panel, select the correct CT volume from the CT-Volume dropdown. The volume is immediately shown in all 2D slice views.
  4. Select the phantom type from the Phantomtyp dropdown. The status label updates to show the available rods and the registration method.
Tip: When multiple volumes are loaded, switch between them freely — the 2D views always follow the current selection.
Section 3

Interface

The module panel is divided into two collapsible sections:

Phantom-Setup — volume and phantom-type selection. The status label summarises the loaded geometry and registration landmarks for the current phantom.

Segmentierung (Segmentation) — the main workflow buttons, in order of use:

Button Function Availability
Seeds setzen / Markups setzen (2 Linien) Starts the markup placement mode for the selected phantom type. Label changes automatically. All phantoms
Segment Phantom Computes the phantom-to-CT transform and fills all rod cylinders. All phantoms
Flip Applies the alternative rod-axis orientation. Click again to revert. REF, Z only
Lunker entfernen Removes voxels with HU < −250 and a 2-voxel margin from all segments. P, Z only
Regression / Statistik Computes segment statistics; runs weighted linear regression for the QMC-Phantom. All phantoms
vBMD Volume erzeugen Applies CaHA = m·HU + b to the entire CT to produce a vBMD volume. REF only, after regression

Auswertung (Analysis) — regression and vBMD export.

Section 4

Phantom Workflows

REF

QMC-Phantom

Segments: Ref_800Ref_600Ref_400Ref_200Ref_100Ref_000
  1. Select QMC-Phantom from the Phantomtyp dropdown.
  2. Click Seeds setzen. A dialog instructs you to place 2 seeds.
  3. Click inside Rod Ref_800 (highest density, brightest on CT), then inside Rod Ref_400. Placement stops automatically after the second confirmed click.
  4. Click Segment Phantom:
    • Region-growing extracts the two seed rods within their HU windows.
    • PCA axis determination finds rod endpoints; a 3-point rigid landmark transform maps phantom → CT.
    • The orientation with the lower RMS landmark error is applied automatically.
    • All six cylinders are rasterised into Phantom_Segmentierung.
  5. Inspect the result. If the segmentation appears mirrored, click Flip. Clicking again reverts.
  6. Click Regression / Statistik to compute mean HU per rod and run weighted linear regression: CaHA = m · HU + b. Results appear in a dialog and are written to Phantom_Regression_Error.
  7. Optionally click vBMD Volume erzeugen to produce a scalar volume with each voxel converted to mg CaHA/cm³.
P

MicroCT-Phantom

Segments: P_800P_100P_030P_-20

Registration uses two user-placed markup lines rather than region-growing — precise pose estimation for short (12 mm) parallel rods.

  1. Select MicroCT-Phantom from the Phantomtyp dropdown.
  2. Click Markups setzen (2 Linien). A dialog explains the two placement steps.
  3. Line 1 — Rod P_800 axis (P800_Achse): click the upper endpoint of rod P_800's long axis, then its lower endpoint.
  4. The module switches automatically to Line 2 after a brief pause.
  5. Line 2 — Cross-orientation (P800_zu_P030): click the upper endpoint of P_800 again, then the centre of rod P_030 (diagonally opposite in the XZ plane).
  6. Click Segment Phantom:
    • Three CT landmarks are mapped to phantom coordinates via a rigid landmark transform — no region-growing is performed.
    • All four cylinders are rasterised.
  7. If air voids are visible, click Lunker entfernen.
  8. Click Regression / Statistik for segment statistics (no regression — reference values not available).
Note: Line 1 endpoint order does not matter — the module identifies the "upper" end by proximity to the start of Line 2.
Z

3Dprinted-QMC

Segments: Z_800Z_600Z_300Z_100Z_000Z_-30
  1. Select 3Dprinted-QMC from the Phantomtyp dropdown.
  2. Click Seeds setzen. A dialog instructs you to place 2 seeds.
  3. Click inside Rod Z_800 (highest density), then inside Rod Z_300. Placement stops automatically.
  4. Click Segment Phantom. Workflow identical to QMC-Phantom: region-growing → PCA → landmark transform → cylinder rasterisation.
  5. If the orientation is mirrored, click Flip.
  6. If printing artefacts or air inclusions are visible, click Lunker entfernen.
  7. Click Regression / Statistik for segment statistics.
Section 5

Post-Processing

Void Removal — Lunker entfernen

3D-printed phantoms can contain localised air pockets that bias density measurements. Clicking Lunker entfernen applies the following to every segment in Phantom_Segmentierung:

  1. Identify all segment voxels with HU < −250.
  2. Dilate the void mask by 2 voxels in all 26 directions (3 × 3 × 3 structuring element).
  3. Zero out the dilated region within the segment. Voxels outside existing segment boundaries are not affected.

The result dialog reports how many segments were modified and the total number of voxels removed.

Regression (QMC-Phantom only)

The module performs weighted least-squares regression CaHA = m · HU + b. Weights account for both phantom manufacturer tolerances (σ_phantom) and HU measurement uncertainty (σ_HU). The final result includes:

  • Calibration equation and R² displayed in a dialog.
  • Per-rod error table written to Phantom_Regression_Error (absolute error, relative error, uncertainty breakdown).

Section 7

Technical Notes

Cylinder geometry. Rod endpoints and radii are read from JSON geometry files in Resources/Geometry/. Cylinder rasterisation is fully vectorised using NumPy meshgrid operations — bounding-box extraction, axis projection, and radial distance test run in a single pass per rod.

Region-growing. A 6-connected BFS flood-fill is seeded from the user-placed point. If the seed voxel falls outside the configured HU window, a 5 × 5 × 5 neighbourhood is searched for the nearest qualifying voxel. Growth is capped at 500 000 voxels to prevent runaway expansion from incorrect seeds.

Flip disambiguation. For the axis-based registration (REF, Z), both orientations of Rod A are tested; the one yielding the lower RMS landmark error is applied automatically. The Flip button swaps the stored best / alternative transforms without re-running segmentation.

Markup-line registration (P-Phantom). Three non-collinear CT landmarks are extracted from two markup lines and mapped to known phantom coordinates via vtkLandmarkTransform in rigid-body mode. The RMS residual is reported in the completion dialog.

Segment naming. All segment identifiers include a phantom-type prefix (Ref_, P_, Z_) so that evaluating all three phantoms in one session populates a single Phantom_Segmentierung node with uniquely named segments, ready for simultaneous statistics export.

Switching phantom types within a session resets markup nodes and transform state. Previously created segments in Phantom_Segmentierung are preserved.
